# 顶层热源倍率诊断实验

该诊断实验冻结现有 PD-GCN checkpoint，仅扫描显式顶层热源倍率

\[
\Delta T_{\mathrm{source}}^{\mathrm{corr}}
=\alpha_Q\Delta T_{\mathrm{source}}.
\]

诊断使用多层 rollout 的 `source_multiplier_alpha_q` 参数。二者直接对应：

```text
source_multiplier_alpha_q = alpha_Q
```

因此，`alpha_Q=1.0` 是无补偿基线，`alpha_Q=1.2` 表示总显式热源温升为原来的 1.2 倍。缩放后的 `delta_T_source` 在当前步进入 PD-GCN 面内传热和厚度方向隐式 FDM，更新后的温度继续作为下一步 rollout 状态。诊断期间旧的 `post_fdm_source_compensation_alpha` 固定为 0，避免两种补偿重复叠加。

## 运行方法

在仓库根目录运行：

```powershell
D:\ProgramData\CondaEnv\PIGNN\python.exe inference\source_alpha_diagnostic_entry.py `
  --config configs\source_alpha_diagnostic.example.json
```

可通过命令行覆盖 checkpoint、输入目录和输出目录：

```powershell
D:\ProgramData\CondaEnv\PIGNN\python.exe inference\source_alpha_diagnostic_entry.py `
  --config configs\source_alpha_diagnostic.example.json `
  --checkpoint runs\pdgcn\checkpoint.pt `
  --h5-dir multilayer_hdf5 `
  --output-dir runs\pdgcn\source_alpha_diagnostic
```

诊断程序逐个 case、逐个倍率运行完整 rollout，但不会为每次扫描保存完整预测温度场，避免产生大量重复 HDF5 文件。

## 配置字段

示例配置位于 `configs/source_alpha_diagnostic.example.json`。

| 字段 | 说明 |
| --- | --- |
| `base_inference_config` | 基础多层推理配置，复用层数、层间距、平滑、FDM、模型和 checkpoint 配置。 |
| `alpha_q_values` | 待扫描的总热源倍率，允许范围 `[1, 2]`；必须包含 `1.0` 才能得到原始基线。 |
| `output_dir` | CSV、JSON 和 PNG 诊断结果目录。 |
| `h5_dir` | 含多层 FEM 数据的 HDF5 目录；为 `null` 时沿用基础推理配置或训练数据目录。 |
| `fem_temperature_dataset` | FEM 温度数据集，要求形状为 `[T,L,N,1]`。 |
| `fem_valid_mask_dataset` | 可选 FEM 有效掩码，形状与温度相同；数据集不存在时默认全部有效。 |
| `fem_frame_offset` | 预测第 0 帧对应的 FEM 帧偏移。`0` 与现有批量结果的同索引比较一致；若需按 transition 将首个预测对齐 FEM 第 1 帧，可设为 `1`。一次实验中必须保持一致。 |
| `max_cases` | 调试时限制 case 数；正式实验设为 `null`。 |
| `write_plots` | 是否生成汇总图和各倍率全局峰值一致性图。 |

## 输出结果

- `source_alpha_case_metrics.csv`：每个倍率、每个 case 的全局峰值、各层峰值 bias、全场及各层 RMSE/MAE。
- `source_alpha_summary.csv`：每个倍率的全局峰值拟合斜率、截距、R²、前两层峰值 bias 和 pooled 全场误差。
- `source_alpha_diagnostic.json`：实验路径、参数映射、失败记录和完整汇总。
- `source_alpha_summary.svg`：斜率、截距、前两层峰值 bias 和全场 RMSE 随倍率变化。
- `source_alpha_global_peak_agreement.svg`：每个倍率下的 FEM/预测全局峰值散点、拟合线和 1:1 线。SVG 不依赖 Matplotlib 原生渲染 DLL，可直接在浏览器和 Typora 中查看并无损用于论文排版。

所有 signed bias 均统一定义为：

\[
\mathrm{bias}=T_{\mathrm{prediction}}-T_{\mathrm{FEM}}.
\]

正式选择倍率时，不应只选择截距最接近 0 的点，还要同时检查拟合斜率是否接近 1、第一二层峰值 bias 是否接近 0，以及全场 RMSE 是否恶化。参数选择应使用训练集或独立校准集，最终测试集只用于一次性报告泛化结果。
